04 · Under the hood

Architecture & data model

Classic three-tier MERN. The frontend never trusts its own prices — every order is re-priced and stock-checked on the API before anything is saved.

Frontend — React 18 + Vite

  • Tailwind CSS design system (evergreen/gold tokens)
  • TanStack Query for server state, Zustand for cart/auth
  • React Router — 13 routes incl. protected /admin
  • Hand-rolled SVG charts (zero chart libraries)

Backend — Express + MongoDB

  • JWT auth, bcrypt hashing, role-based guards
  • Zod request validation + central error handler
  • Pricing engine: coupons, free-shipping threshold, COD
  • Atomic stock reservation with rollback
  • Helmet, CORS allowlist, rate limiting
